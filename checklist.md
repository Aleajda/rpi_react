Чек-лист для проверки лабораторных работ с 1 по 4 включительно.

1. Запуск и общая работоспособность
    a)	Сервер запускается 
    b)	Нет ошибок в терминале при старте
    c)	Подключение к PostgreSQL успешно
    d)	React-приложение запускается
    e)	Нет ошибок в консоли браузера
    f) 	Приложение загружает данные с сервера
2. Работа с изображениями
    a)	Регистрация пользователя с загрузкой avatar (multipart/form-data) (показать создание нового пользователя. Заранее подготовить фото для аватарки)
    b)	Файлы сохраняются в папке server/static
    c)	Изображение открывается по прямой ссылке в браузере
    d)	В БД хранятся пути вида /static/filename.jpg
3. Отображение изображений на клиентской части
    a)	GET /offers возвращает данные о предложениях, в том числе с полным URL изображений
    b)	Фотографии оффера отображаются
    c)	Аватары пользователей отображаются
4. Авторизация
    a)	POST /login возвращает token
    b)	Защищенные маршруты требуют токен
    c)	Без токена возвращается 401
5. Работа с отзывами

    b)	GET /reviews/:offerId возвращает список
